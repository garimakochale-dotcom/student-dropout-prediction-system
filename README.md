# Student Dropout Prediction System using Machine Learning & Power BI
This project predicts students who are at risk of dropping out using Machine Learning techniques and visualizes insights through an interactive Power BI dashboard.
The system helps educational institutions identify high-risk students early and support intervention-based decision-making.

# Project Features
• Student dropout prediction using Machine Learning
• Risk level classification
• SHAP explainability analysis
• Interactive Power BI dashboard
• Student intervention system
• Risk segmentation and analytics

# Technologies Used
• Python
• Pandas
• NumPy
• Scikit-learn
• SHAP
• Matplotlib
• Seaborn
• Power BI
• Jupyter Notebook

# Dashboard Features
Page 1: Student Risk Overview
• Total Students KPI
• High Risk Students KPI
• Predicted Dropout Rate
• Risk Distribution
• Attendance vs Marks Analysis
• Dropout Probability Distribution

Page 2: Student Intervention Panel
• High Risk Student List
• Risk Summary
• Student-Level Insights
• Interactive Filters

 # Key Insights
• Low attendance strongly impacts dropout risk
• Low participation increases dropout probability
• High-risk students require early intervention
• Explainable AI improves prediction transparency

# Project Outcome
The project successfully combines:
• Machine Learning
• Explainable AI
• Business Intelligence
• Dashboard Analytics
to create a complete student risk prediction and intervention system.
